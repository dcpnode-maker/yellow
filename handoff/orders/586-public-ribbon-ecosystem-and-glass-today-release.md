## Review finding repair — 2026-09-22

The first independent public-browser pass found that the Ecosystem navigation button
used `/p/<property>/ecosystem`, while the deployed server intentionally exposes this
lazy workspace through the established Today query route. The admitted repair maps
`workflow("ecosystem")` to `/p/<property>/today?workspace=ecosystem` and adds a
focused source assertion. It changes no backend route, permission or data behavior;
the reviewer must retest the actual public click before acceptance.

The continued guarded browser pass also exposed a deterministic CSP console error:
the inherited stylesheet requested Google Fonts even though the public CSP correctly
permits only self-hosted styles. The admitted repair removes that external import and
uses the stylesheet's existing local/system fallbacks. This removes a third-party
request, improves startup/privacy/offline behavior and requires final visual and
console retesting.
