PART TWOThree cost ledgers

Cost shows up in three places. Most teams optimise the smallest one.

1 · Run cost — ₹0–4,000/month

Oracle Cloud Always Free across two founder tenancies (primary + replica), encrypted backups off-provider, Caddy, Valkey, self-hosted monitoring. Only PostgreSQL is stateful; everything else is derived and rebuildable.

Projected at 500 properties: $0.28–2.00 per property/month against competitor pricing of $50–300. That gap is the moat.

2 · Build cost — ₹21–28k/month

Subscriptions, not credits. Max 20x for the primary builder, a smaller plan for the second founder, and a tiny credit float as an overflow valve only.

The same token volume through prepaid API credits would run ₹15L+. Subscription pricing is the single largest cost decision in the project.

3 · Avoided cost — the ledger nobody writes down

Design defects get exponentially more expensive with time. Four were caught before a line of application code existed:

months → hoursDouble-sell under load. The occupancy constraint we'd settled on paper allowed a private room to be sold over live bed sales. Found by a 50-thread stress test. After launch this corrupts reservations, revenue, and trust simultaneously.
breach → 1 lineCross-tenant leak through views. PostgreSQL views bypass row-level security by default; one hotel could read a competitor's rates. Missed by my review and a second model's. Found by a two-tenant fixture.
ledger migrationFolio ownership. Folios belong to accounts, not reservations — caught in research round one. Wrong, it's a financial-history migration under live data.
days eachFixture and test defects. Truncated JSON schema, a non-existent column, a wrong CHECK value — the database rejected its own author twice.

Nine research rounds and one afternoon of stress testing converted an expensive class of surprise into a cheap one. That is what the package bought.

PART THREEThe mechanisms that keep it cheap

Model routing — the biggest lever on build cost

Fable 5 costs several times more per finished task than Opus 5. It earns that on ambiguous problems; nine rounds of research exist precisely to remove ambiguity from the rest.

ModelWhere it runs
Fable 5Phase kickoff and end-of-phase gates · anything touching schema, occupancy claims, ledger, fiscal chains, RLS · concurrency debugging · decisions logged
Opus 5Default working model — feature implementation, adapters, refactors, API handlers
Sonnet 5Scaffolding, tests from specs, docs, seed data, first-pass log triage

The escalation rule matters more than the split: if a cheap session hits an invariant question, it stops, states the question, switches to Fable, decides, logs it, and switches back. No cheap session ever quietly decides an expensive thing.

Spend triggers — nothing is bought before it's needed

Every dropped service has a named condition that turns it back on, so cost tracks revenue rather than anxiety:

  • ₹4k/mo Hetzner — once properties are paying
  • Managed PostgreSQL — if ops exceeds budget two months running
  • Fiscal provider — at jurisdiction #3 (UAE already forces one legally)
  • Channel manager — when the OTA long tail matters more than the fee
  • ClickHouse — when DuckDB queries take seconds
  • Failover + SSO/SAML — at the first enterprise SLA

Dependency discipline — cost that arrives as a surprise later

MinIO was open source (AGPLv3) the entire time and still stripped its community console, stopped shipping binaries, and archived the repo in early 2026. Licence text was never the protection. Ours is: permissive licences for anything embedded, governance that isn't a single company, and standard protocols so a vendor is a config line — S3, SQL, OCI images, WireGuard, VAPID. Class C dependencies (a physical host, OTA marketplaces, payment rails, government endpoints) are accepted honestly rather than chased.

Architecture choices that are also cost choices

  • One precious datastore. PostgreSQL does queueing (outbox), constraints (occupancy), search (FTS), and time travel (fact log) — services we'd otherwise run, patch, and pay for.
  • Modular monolith. Thirteen contexts, one deployable. No inter-service network, no distributed transactions, no orchestration bill.
  • Data over code. Verticals, tax regimes, policies, and statutory rules are extension rows. A new country is usually a row, not a release.
  • One PWA, seven surfaces. Front desk, kiosk, housekeeping mobile, owner portal — one codebase, no app stores, no native duplication.

PART FIVEWhat still costs money

Honesty is cheaper than optimism.

  • Certifications take calendar time, not money — Booking.com and Expedia partner programmes, ZATCA sandbox, India IRP access, a UAE ASP vendor. Start them now; they gate Phases 8–9 and 12.
  • The free tier has no SLA. Oracle can reclaim idle instances. That's why backups live off-provider, why there are two tenancies, and why monthly restore drills are doctrine rather than aspiration.
  • Self-hosting trades vendor cost for founder hours. Correct at zero revenue; the trigger list is what stops it becoming permanent.
  • The remaining 30% is code. The package makes it derivable; Phases 0–12 derive it. No document shortens that work — it only stops it being done twice.
