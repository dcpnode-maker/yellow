What this comparison proves

This page does not navigate to, capture, fetch or re-render any source URL. It compares only the two local image files you supply. A strict decoded-pixel match is meaningful only when both artifacts were captured with the same viewport, state, fonts, device-pixel ratio and browser. A match does not prove that either input is an approved reference, and no target equality has been established in advance.

Maximum per file: 20 MiB and 8,500,000 decoded pixels. Images must have exactly equal decoded dimensions. The comparison never resizes, crops, masks or applies a tolerance.
