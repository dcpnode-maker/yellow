# Yellow profile study assets

Order442 · 2026-09-06. These assets serve the fictional study only. Production
does not assign these portraits to real identities and adds no external asset request.

## Visual references

- [Profile Card — Tran Mau Tri Tam / UI8](https://dribbble.com/shots/26033069-Profile-Card), especially the right-hand Sophie Bennett card. Original 3200×2560 artwork was inspected in scratch; it is not a shipped product asset.
- [Synthex — Jack R. / RonDesignLab](https://dribbble.com/shots/27131881-Synthex-UI-Analytics-SaaS-Dashboard) supplies secondary type/palette inspiration. The user subsequently authorized an improved original composition.

## Product assets

- `guest-mira.png`: ImageGen-generated fictional Mira Shah. Native1024×1536 PNG, unchanged from output. Ivory knit, soft sage background and continuous pale lower portrait.
- `staff-aditi.png`: ImageGen-generated fictional Aditi Rao. Native1024×1536 PNG, unchanged from output. Ivory jacket, olive blouse and softly defocused lower portrait.
- `Urbanist.ttf`: unmodified regular variable font from [Corey Hu / Urbanist](https://github.com/coreyhu/Urbanist/blob/main/fonts/variable/Urbanist%5Bwght%5D.ttf), Git blob6177f2d6e64f4074d2bac40daaba5ac0895638e6. SIL OFL1.1 retained in `Urbanist-OFL.txt`.
- Named `.svg` files: unmodified regular icons from [Phosphor Icons](https://github.com/phosphor-icons/core/tree/main/assets/regular). MIT notice retained in `Phosphor-LICENSE.txt`. These are source icons, not handcrafted approximations.

Generation used the original profile board as surface/composition direction and explicitly requested a distinct fictional adult, no text, logo or UI. No face-identification or real hotel record was used. The images are not evidence of a working app or visual QA.

Both images use the same portrait composition ratio; CSS may crop them to the card slot. Font and images are served by a fixed local allowlist. This adds no runtime dependency or third-party script.
